# 第八轮优化方案 - 移除Shift策略与全面架构优化

**优化时间**: 2025-10-29  
**基准版本**: 优化版本1 (R²=-0.28, MAPE=4.81%)  
**优化目标**: 移除shift(1)限制,增加有效样本,通过特征工程和架构优化突破性能瓶颈

---

## 📊 问题分析

### 当前限制 (优化版本1)
1. **有效样本不足**: shift(1)导致样本从1167降至228 (损失80%数据)
2. **特征质量**: price_lag_1占SHAP重要性78.5%,过度依赖单一特征
3. **架构限制**: 256-128-64 LSTM可能对小样本过拟合

### 优化机会
- ✅ 移除shift(1): 恢复1000+样本,提升训练数据量
- ✅ 特征工程: 降低price_lag_1主导性,引入更多有效信号
- ✅ 架构调整: 适配更多样本的模型复杂度
- ✅ 学习率优化: 配合新架构调整衰减节奏

---

## 🔧 优化版本8 - 配置方案

### 1. 移除Shift(1)策略

**修改前 (优化版本1)**:
```python
# 价格变化 - 使用shift(1)
df['price_return'] = df[target].pct_change().shift(1)
df['ma_5'] = df[target].rolling(5).mean().shift(1)
# ... 所有技术指标都shift(1)
```

**修改后 (优化版本8)**:
```python
# 移除shift(1),直接计算当前值
df['price_return'] = df[target].pct_change()
df['ma_5'] = df[target].rolling(5).mean()
# 仅保留滞后特征的shift (price_lag_1等已经是滞后的)
```

**预期效果**:
- 有效样本: 228 → ~1077 (增加374%)
- 训练数据更充足,减少过拟合风险

---

### 2. 特征工程改进

#### A. 降低price_lag_1主导性
```python
# 策略1: 减少过度相关的滞后特征
for lag in [1, 3, 7]:  # 从[1,2,3,5,7,10]减少到3个
    df[f'price_lag_{lag}'] = df[target].shift(lag)

# 策略2: 增加差分特征 (捕捉趋势变化)
df['price_diff_1'] = df[target].diff(1)
df['price_diff_7'] = df[target].diff(7)
df['price_diff_30'] = df[target].diff(30)

# 策略3: 增加技术分析指标
# MACD
ema_12 = df[target].ewm(span=12).mean()
ema_26 = df[target].ewm(span=26).mean()
df['macd'] = ema_12 - ema_26
df['macd_signal'] = df['macd'].ewm(span=9).mean()

# 布林带
df['bb_upper'] = df['ma_20'] + 2 * df['volatility_20']
df['bb_lower'] = df['ma_20'] - 2 * df['volatility_20']
df['bb_position'] = (df[target] - df['bb_lower']) / (df['bb_upper'] - df['bb_lower'])
```

#### B. 排除冗余特征
```python
# 移除与price_lag_1高度相关的特征
redundant_features = [
    'ma_10',      # 与price_lag_1相关性>0.95
    'ma_5',       # 与price_lag_1相关性>0.97
    'ema_12',     # 高相关
    'ema_26',     # 高相关
]
```

### 3. 模型架构调整

**策略**: 更多样本 → 可以支持更复杂模型 → 提升LSTM容量

#### 修改前 (优化版本1)
```python
CONFIG = {
    'sequence_length': 90,
    'lstm_units': 256,
    'lstm_units_2': 128,
    'lstm_units_3': 64,
    'attention_dim': 128,
    'dropout_rate': 0.4,
}
```

#### 修改后 (优化版本8)
```python
CONFIG = {
    'sequence_length': 60,      # 减少至60 (更多样本可用)
    'lstm_units': 320,          # 增加至320 (更强特征提取)
    'lstm_units_2': 160,        # 增加至160
    'lstm_units_3': 80,         # 增加至80
    'attention_dim': 160,       # 增加至160
    'dropout_rate': 0.35,       # 降至0.35 (样本多,减少正则化)
    'l2_reg': 0.0005,          # 降低L2正则化
}
```

**理由**:
- 更多样本支持更大模型容量
- 减少序列长度(60),提高训练效率
- 降低dropout,充分利用数据

#### A. 调整学习率

CONFIG = {
