## 🎲 关键创新点:损失函数微调

### 调整方向权重

| 版本 | Huber权重 | 方向权重 | R²结果 | MAPE结果 |
|------|-----------|----------|--------|----------|
| 优化版本1 | 80% | 20% | -0.28 | 4.81% |
| 优化版本3 | 90% | 10% | -6.15 | 11.99% |
| **优化版本4** | **95%** | **5%** | **?** | **?** |

### 代码实现
```python
def directional_loss(y_true, y_pred):
    # Huber损失(对异常值鲁棒)
    huber = tf.keras.losses.Huber(delta=1.0)(y_true, y_pred)
    
    # 方向损失计算
    direction_component = compute_direction_loss()
    
    # 组合损失:95% Huber + 5% 方向
    # 进一步降低方向权重,聚焦R²优化
    total_loss = 0.95 * huber + 0.05 * direction_component
    
    return tf.where(tf.math.is_nan(total_loss), huber, total_loss)
```

### 调整理由
1. **R²与MSE直接相关**: R² = 1 - (SS_res / SS_tot),优化MSE即优化R²
2. **Huber Loss本质是鲁棒的MSE**: 更高权重直接提升R²
3. **方向损失与R²无直接关系**: 降至5%保留方向感知但不干扰主要优化目标
4. **渐进式调整**: 80%→90%→95%,温和调整避免突变

## 💡 关键洞察

### 为什么优化版本1的shift(1)有效?

#### 假设1: 序列模型的时间对齐
- LSTM在t时刻使用[t-90, t-1]预测t+sequence_length
- 若技术指标不shift,可能包含"未来信息"的微妙泄露

#### 假设2: 数据集的特殊性
- data.dta的时间戳对齐可能有特殊性
- shift(1)可能无意中修正了数据对齐问题

#### 假设3: 正则化效应
- shift(1)相当于额外的信息延迟层
- 类似dropout的正则化作用,防止过拟合

**验证**: 第四轮训练后分析训练集和测试集表现差异
