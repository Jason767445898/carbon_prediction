### 2. 移除CosineDecay学习率调度 ✅
```python

    initial_learning_rate=0.0001,
    decay_steps=15000,
    alpha=0.05  # 最终学习率为5e-06
)

# 实验B新配置:

# 使用常量初始学习率0.0001,配合ReduceLROnPlateau动态调整
```

**理由**: 
- 优化版本1在Epoch 294时学习率已衰减至5e-06
- CosineDecay导致学习率过早、过快衰减
- 可能未充分探索参数空间即收敛

---

### 3. 恢复ReduceLROnPlateau回调 ✅
```python
ReduceLROnPlateau(
    monitor='val_loss',
    patience=20,       # 20个epoch验证损失无改善才降低学习率
    factor=0.7,        # 学习率降低至原来的70%
    min_lr=1e-7,       # 最低学习率1e-7(比CosineDecay的5e-06更小)
    verbose=1
)
```

**优势**:
- **动态调整**: 根据实际训练情况自适应降低学习率
- **更保守**: patience=20比CosineDecay的固定衰减更耐心
- **可逆性**: 训练效果不好时可尝试不同的factor
- **避免过早收敛**: 仅在真正需要时才降低学习率
