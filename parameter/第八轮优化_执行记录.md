### 2. 特征工程修改

#### A. 移除shift(1)策略
**修改内容**:
- 所有技术指标不再使用`.shift(1)`
- 直接计算当前值的技术指标
- 保留lag特征的shift (如price_lag_1本身就是滞后的)

**预期效果**:
- 有效样本: 228 → ~1077 (+374%)

#### B. 减少滞后特征冗余
```python
# 修改前: 6个lag
for lag in [1, 2, 3, 5, 7, 10]:
    df[f'price_lag_{lag}'] = df[target].shift(lag)

# 修改后: 3个关键lag
for lag in [1, 3, 7]:
    df[f'price_lag_{lag}'] = df[target].shift(lag)
```

#### C. 新增特征

**差分特征** (捕捉趋势变化):
```python
df['price_diff_1'] = df[target].diff(1)
df['price_diff_7'] = df[target].diff(7)
df['price_diff_30'] = df[target].diff(30)
```

**MACD指标** (趋势和动量):
```python
ema_12 = df[target].ewm(span=12).mean()
ema_26 = df[target].ewm(span=26).mean()
df['macd'] = ema_12 - ema_26
df['macd_signal'] = df['macd'].ewm(span=9).mean()
df['macd_hist'] = df['macd'] - df['macd_signal']
```

**布林带指标** (超买超卖):
```python
df['bb_upper'] = df['ma_20'] + 2 * df['volatility_20']
df['bb_lower'] = df['ma_20'] - 2 * df['volatility_20']
df['bb_position'] = (df[target] - df['bb_lower']) / (df['bb_upper'] - df['bb_lower'])
df['bb_width'] = (df['bb_upper'] - df['bb_lower']) / df['ma_20']
```

## 🎯 优化目标与假设

### 核心假设
1. **更多样本 → 更好泛化**
   - shift(1)导致80%样本损失
   - 移除后样本增加374%,可能改善R²

2. **特征质量 > 特征数量**
   - 减少冗余lag (6→3)
   - 新增MACD/布林带等高质量技术指标
   - 预期降低price_lag_1主导性

3. **更大模型容量匹配更多样本**
   - LSTM单元: 256→320, 128→160, 64→80
   - Attention: 128→160
   - 降低dropout/L2,充分学习

4. **更高学习率配合更长训练**
   - 学习率: 0.0001→0.0002
   - Epochs: 300→400
   - 给予充分优化时间

### 预期性能
- **乐观**: R²=-0.28 → 0.1~0.3, MAPE=4.81% → 3.5~4.2%
- **保守**: R²=-0.28 → -0.1~0, MAPE=4.81% → 4.2~4.6%
- **最差**: 与优化版本1持平

## ⚠️ 风险评估

### 已识别风险
1. **轻微数据泄露**: 移除shift(1)可能引入当期信息
   - **缓解措施**: 保留lag特征的shift,不使用未来数据

2. **训练时间增加**: 1077样本 × 400 epochs
   - **预计时间**: 25-30分钟
   - **缓解措施**: 使用caffeinate防休眠

3. **模型过拟合**: 更大模型容量
   - **缓解措施**: 保持dropout=0.35和L2=0.0005

4. **特征工程失败**: 新增特征可能无效
   - **备选方案**: 可回退到优化版本1
