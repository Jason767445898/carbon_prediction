## 🔍 特征工程修复

### 问题诊断

优化版本2的核心问题:
- ❌ 所有技术指标都使用了shift(1)
- ❌ 导致有效样本从795降至228
- ❌ 信息延迟严重,模型无法学习有效模式

### 修复方案

#### 1. 正确理解数据泄露
```python
# ✅ 需要lag的: 仅当前期原始价格
for lag in [1, 2, 3, 5, 7, 10]:
    df[f'price_lag_{lag}'] = df[target].shift(lag)

# ✅ 无需lag的: 技术指标(已基于历史计算)
df[f'ma_{window}'] = df[target].rolling(window).mean()  # 移除shift(1)
df[f'ema_{span}'] = df[target].ewm(span=span).mean()   # 移除shift(1)
df[f'volatility_{window}'] = df[target].rolling(window).std()  # 移除shift(1)
```

**原理**: 
- 移动平均在t时刻的值是基于[t-window, t-1]的价格计算,本身不包含t时刻价格
- RSI、MACD等指标同理,都是基于历史数据的衍生指标
- 只有`df[target]`(当前期价格)才需要shift

#### 2. 特征排除列表优化
```python
# 优化版本2(错误): 过度排除
leakage_features = [
    'log_carbon_price_hb_ea',
    'log_transactionamount_hb_ea',  # ❌ 交易量是独立变量,不应排除
    'log_transactionamount_hb_ea_sqr',
    'price_return',  # ❌ 衍生特征,不应排除
    'price_diff'
]

# 优化版本3(正确): 仅排除目标变量的直接变换
leakage_features = [
    'log_carbon_price_hb_ea',  # ✅ 目标变量的对数(真正的泄露)
]
```
