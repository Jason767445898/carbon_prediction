## 🚀 第二轮优化 (2025-10-30)

### 优化目标
**重大架构升级**: 引入标准Scaled Dot-Product Attention

### 核心改进
1. **Attention机制升级**
   ```python
   # 之前: 简单权重Attention
   attention = Dense(dim, activation='tanh')(input)
   
   # 现在: Scaled Dot-Product Attention
   Q, K, V = Dense(dim)(input), Dense(dim)(input), Dense(dim)(input)
   scores = softmax(Q@K.T / sqrt(dim))
   output = scores @ V
   ```

2. **残差连接** (Residual Connection)
   ```python
   lstm_pooled = GlobalAveragePooling1D()(lstm_out)
   combined = Add()([lstm_pooled, attention_out])
   combined = LayerNormalization()(combined)
   ```

3. **Layer Normalization**
   - Transformer标准组件
   - 提升训练稳定性

### 优化策略
- Attention维度: 192/256
- 正则化调整: dropout 0.35-0.45, l2 0.0005-0.0015
- 训练轮数: 300-500
- 模型深度: 3层LSTM vs 4层LSTM

### 🏆 最优配置: Round2_Config3_BiggerAttention
```python
sequence_length: 60
lstm_units: 384-192-96
attention_dim: 256  # ⭐ 关键改进! (192→256)
dropout_rate: 0.4
l2_reg: 0.001
learning_rate: 0.00015
epochs: 400
```

### 关键发现
1. ✅ **Attention维度256显著优于192** (R²: 0.219 vs 0.109)
2. ✅ **新Attention机制带来质的飞跃** (R²从-0.036到0.219)
3. ❌ **降低正则化导致严重过拟合** (R²<-1)
4. ❌ **增加epochs效果不佳** (R²=-0.62)
5. ⚠️ **方向准确率仍偏低** (仅29.87%)

### 性能指标
- **R²**: 0.219 ✅ **(首次突破0!)**
- **RMSE**: 126.74 **(↓13%)**
- **MAPE**: 10.89% **(↓17%)**
- **方向准确率**: 29.87%

## 💡 关键经验总结

### ✅ 成功经验

1. **Attention维度至关重要**
   - 192 → 256: R²从0.109提升至0.219
   - 继续探索更大维度(320/384)

2. **标准Attention机制效果显著**
   - Scaled Dot-Product > 简单权重
   - 残差连接提升稳定性

3. **适度模型容量最优**
   - LSTM 384-192-96 表现最佳
   - 更深(448-224-112)效果下降

4. **学习率0.00015表现稳定**
   - 多轮优化中持续最优
   - CosineDecay策略有效

### ❌ 失败教训

1. **过度降低正则化导致崩溃**
   - dropout 0.35, l2 0.0005 → R²<-1
   - 保持0.4和0.001较安全

2. **盲目增加epochs无效**
   - 400 → 500: R²从0.219降至-0.62
   - EarlyStopping更重要

3. **方向准确率提升困难**
   - 方向损失权重0.20可能不够
   - 需要专项优化策略

### 🎯 优化方向启示

1. **架构创新 > 超参微调**
   - 第二轮Attention升级带来质的飞跃
   - 第三轮探索多头注意力

2. **特征质量是基础**
   - 移除shift(1)增加样本数
   - 排除泄漏特征提升鲁棒性

3. **方向预测需要专项设计**
   - 考虑单独的方向分类器
   - 探索对比学习方法
