### 核心诊断
从优化版本1的备份文档分析:

1. **R²为负的主要原因**:
   - 测试集上模型预测方差小于实际值方差
   - 可能的验证集与测试集分布差异
   - 损失函数(Huber+方向)与R²评估指标不完全一致
   
2. **过度依赖price_lag_1**:
   - SHAP重要性78.5%集中在一个特征
   - 其他48个特征几乎被忽略
   - Attention机制未能有效分散注意力

3. **训练过程问题**:
   - 学习率衰减过快(Epoch 294时仅5e-06)
   - 可能过早收敛,未充分探索参数空间
   - EarlyStopping patience=40可能过短

### **实验C: 特征工程优化** 🧪

**核心思路**: 解决price_lag_1过度主导问题

**策略**:
1. 在模型输入前对price_lag特征进行**降权**
2. 增强其他技术指标的信号强度

**代码修改**:
```python
# 在数据预处理阶段添加特征工程
def apply_feature_engineering(data):
    # 对价格lag特征进行缩放,降低其主导性
    price_lag_cols = ['price_lag_1', 'price_lag_2', 'price_lag_3']
    for col in price_lag_cols:
        data[col] = data[col] * 0.5  # 降权50%
    
    # 对技术指标进行增强
    tech_indicators = ['rsi', 'volatility', 'momentum', 'ma_5', 'ma_10', 'ema_12', 'ema_26']
    for col in tech_indicators:
        data[col] = data[col] * 1.5  # 增强50%
    
    return data
```

**其他参数保持优化版本1不变**

**预期**:
- R²: -0.15 ~ 0.00 (改善)
- MAPE: 5.0% ~ 6.0% (可能略差)
- 方向准确率: 54% ~ 56% (改善)
